# Игра «Угадай число» на Python

Программа загадывает случайное число от 1 до 100.

Пользователь должен угадать его за ограниченное количество попыток. Поддерживаются три уровня сложности, подсказки и возможность сыграть ещё раз.

## Возможности

- выбор уровня сложности;

- случайное число от 1 до 100;

- подсказки: больше или меньше загаданное число;

- подсчёт количества попыток;

- возможность перезапустить игру после завершения.

## Уровни сложности

| Уровень | Сложность | Количество попыток |

| 1 | Легкий | 10 |

| 2 | Средний | 5 |

| 3 | Трудный | 3 |
